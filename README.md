# mk-asia-guide

## 项目简介

mk-asia-guide 是一个用于归档和发布多个独立 HTML 页面的仓库。这些页面内容涵盖亚洲地区相关的参考信息、实用指南或资料整理，以静态 HTML 文件形式提供，便于直接浏览和分享。

本仓库不针对任何特定网站或服务，仅作为 HTML 页面的集中存放与版本管理用途。

## 目录说明

```
mk-asia-guide/
├── pages/          # 存放所有 HTML 页面文件
├── assets/         # 页面引用的静态资源（CSS、图片、字体等）
├── docs/           # 附加文档或说明
└── README.md       # 本文件
```

- `pages/` 目录下为各个独立 HTML 文件，文件名直观反映页面主题。
- `assets/` 目录按需组织，部分页面可能使用外部资源链接。
- `docs/` 目录可存放与页面相关的背景说明或使用提示。

## 页面归档说明

仓库中的 HTML 页面均为独立文件，可直接在浏览器中打开查看。页面内容可能包含：

- 亚洲地区各类实用信息整理
- 工具或参考资料的静态呈现
- 其他与亚洲主题相关的 HTML 页面

每个页面均保持自包含性，不依赖外部数据库或后端服务。部分页面可能引用通用 CSS 库或字体资源，这些资源已列入 `assets/` 或通过 CDN 加载。
